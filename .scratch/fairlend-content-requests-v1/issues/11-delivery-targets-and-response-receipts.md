# 11 — Track delivery targets and response receipts

**What to build:** Operators can see exactly where a response must go, confirm actual delivery, and trust that Responded means every required obligation has evidence.

**Blocked by:** 10 — Manage deliverable versions and promotion

**Status:** ready-for-agent

- [ ] The original destination is required by default; additional channels default optional.
- [ ] Operators can change whether an additional target is required.
- [ ] Copying content never marks delivery automatically.
- [ ] Mark as responded records channel, destination, exact version, actor, time, and optional note.
- [ ] All required active receipts compute the Responded lifecycle state.
- [ ] Reopening deactivates the current receipt while preserving immutable history.
- [ ] Agents may confirm delivery only from a verifiably successful authenticated integration.
