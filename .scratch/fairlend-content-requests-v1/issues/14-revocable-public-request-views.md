# 14 — Publish revocable public request views

**What to build:** Operators can share explicitly selected request material through a stable unauthenticated page without exposing private founder or operational data.

**Blocked by:** 05 — Implement the Variant G context experience; 10 — Manage deliverable versions and promotion

**Status:** ready-for-agent

- [ ] Operators explicitly select shareable brief sections and promoted deliverables.
- [ ] Public links use cryptographically unguessable per-request tokens.
- [ ] Public pages require no sign-in and permit no mutation.
- [ ] Founder input, private drafts, internal notes, jobs, audits, and candidate versions are excluded.
- [ ] Revocation is immediate and optional expiry is supported.
- [ ] Contract and browser tests inspect the public response shape for private-field leakage.
