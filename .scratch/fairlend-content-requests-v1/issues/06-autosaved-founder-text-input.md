# 06 — Capture autosaved founder text input

**What to build:** Elie can type into the compact or expanded Unified Canvas editor and trust that meaningful progress is saved and reflected in the request lifecycle.

**Blocked by:** 03 — Assignment and founder request library; 05 — Implement the Variant G context experience

**Status:** ready-for-agent

- [ ] Keyboard input is shared between compact and expanded editor states without content loss.
- [ ] Autosave exposes Saved, Saving, and Offline presentation states.
- [ ] Meaningful input advances Pending to In progress; opening alone does not.
- [ ] Founder raw input is immutable to agents and operators outside the founder document workflow.
- [ ] Draft existence is visible to authorized operators without exposing unnecessary private content.
- [ ] Refreshing or switching devices restores the latest durable draft.
