# 03 — Assignment and founder request library

**What to build:** Operators can assign requests and Elie can work from a prioritized mobile library that clearly communicates ownership, urgency, and engagement.

**Blocked by:** 02 — Create, retrieve, and find Content Requests

**Status:** ready-for-agent

- [ ] Each request has exactly one accountable assignee and optional watchers.
- [ ] Reassignment preserves actor, previous owner, new owner, time, and reason.
- [ ] Elie can switch between swipeable stack and grid library views.
- [ ] Manual/Critical requests sort above automated requests in every applicable view.
- [ ] First-open and latest-open timestamps are recorded separately from meaningful progress.
- [ ] Assignment and Critical escalation generate in-app and transactional email notifications.
- [ ] Role authorization prevents unauthorized assignment changes.
