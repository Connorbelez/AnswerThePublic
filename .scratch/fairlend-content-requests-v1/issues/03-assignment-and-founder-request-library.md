# 03 — Assignment and founder request library

**What to build:** Operators can assign requests and Elie can work from a prioritized mobile library that clearly communicates ownership, urgency, and engagement.

**Blocked by:** 02 — Create, retrieve, and find Content Requests

**Status:** done

- [x] Each request has exactly one accountable assignee and optional watchers.
- [x] Reassignment preserves actor, previous owner, new owner, time, and reason.
- [x] Elie can switch between swipeable stack and grid library views.
- [x] Manual/Critical requests sort above automated requests in every applicable view.
- [x] First-open and latest-open timestamps are recorded separately from meaningful progress.
- [x] Assignment and Critical escalation generate in-app and transactional email notifications.
- [x] Role authorization prevents unauthorized assignment changes.
