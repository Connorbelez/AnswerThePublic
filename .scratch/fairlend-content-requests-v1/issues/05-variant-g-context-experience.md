# 05 — Implement the Variant G context experience

**What to build:** Elie can understand a Content Request through the approved Variant G Unified Canvas, with a dominant brief and a stable compact-to-focused editor relationship.

**Blocked by:** 02 — Create, retrieve, and find Content Requests

**Status:** ready-for-agent

- [ ] The Unified Canvas adapts the approved Variant G interaction and visual hierarchy.
- [ ] Context includes original question, source body or summary, operator cue, talking points, research, citations, missing research, and guardrails when available.
- [ ] Context items can be toggled and pinned.
- [ ] Pinned speaking notes display their complete content without truncation.
- [ ] The editor expands through an explicit control and is never user-resizable.
- [ ] Motion is restrained and reduced-motion preferences are honored.
- [ ] Mobile touch, keyboard navigation, focus management, and desktop responsiveness pass browser acceptance tests.
